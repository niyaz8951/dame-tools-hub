How a row is filled
  • Untick Show to leave a row out of the table.
  • Leave Response empty to print the datasheet value as it is.
  • Type a sentence to print the same standard response every time.
  • Remove text takes text out of the datasheet value: + PE turns 380V/3Ph/60Hz + PE into 380V/3Ph/60Hz. Separate several texts with ;.
  • Put $ or * where the datasheet value should go: Panel thickness is $ Thermal break prints Panel thickness is 62 mm Thermal break.
  • Name in Excel changes what is printed in the Component column. Empty keeps the datasheet name.
