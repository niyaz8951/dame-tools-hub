    What comes out

    Coils has one row per coil: source file, where it was found, item number, reference tag and coil type, then every labelled field in the order the quotation prints it — finned height and length, fin spacing, rows, circuits, connections, capacities, air flow, face velocity, temperatures, pressure drops, medium and flow — then the coil code, quantity, the certification note and the quotation header (customer, reference, date, WinCoil version). Numbers are written as numbers, so they sum and filter in Excel. “~” and “-” (not applicable) are left blank. Extraction_Log lists every file and what was found in it.

    Built for WinCoil quotations. A field that appears in only some files still gets its column; coils without it are left blank. Old .doc files need saving as .docx first, and a scanned PDF has no text to read — this tool does not use OCR.
